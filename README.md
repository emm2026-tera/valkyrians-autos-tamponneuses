# Valkyrians – Autos Tamponneuses (démo)

Démo jouable dans le navigateur : choisis ta voiture parmi 6 sur une île flottante dans le ciel, sans murs. Percute les autres pour les pousser hors de l'île : elles tombent sur les nuages et sont éliminées. La dernière voiture sur l'île gagne !

**Jouer :** https://emm2026-tera.github.io/valkyrians-autos-tamponneuses/

## Commandes
- Clavier : flèches / WASD pour conduire · Espace ou J = Fusil à balle géante · K = Lance-filet · L = Fusil à glace · E ou I = Pouvoir spécial
- Mobile (Android) : joystick à gauche, 4 boutons à droite

## Armes
- **Fusil à balle géante** : une seule balle à la fois avec barre de recharge ; repousse fort l'adversaire vers le bord.
- **Lance-filet** : retient l'adversaire sur place pendant 2 s (facile à pousser).
- **Fusil à glace** : l'adversaire perd son adhérence, dérape et glisse plus loin quand on le percute.
- **Pouvoirs spéciaux** : Rose – Rayon de cœur · Bleue – Éclat de cristal · Rouge – Traînée de feu · Verte – Lianes · Violette – Vortex trou noir · Dorée – Rayon éclair.

## Projet Valkyrie
Une part des ventes soutient une fondation pour les femmes victimes d'agression.
